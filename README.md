# Mimi Digital Profile Website

A unique multi-page Resume + Bio-data website created for the Web Technology assignment.

## Pages
- index.html — Home
- resume.html — Resume
- biodata.html — Bio-data
- projects.html — Projects
- contact.html — Contact

## Technologies
HTML5, CSS3, JavaScript and jQuery.

## How to run
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html`.
4. Install the VS Code extension "Live Server" if needed.
5. Right-click `index.html` → Open with Live Server.

## Cloud hosting
Recommended: GitHub Pages.
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to Settings → Pages.
4. Choose Deploy from branch → main → /root.
5. Save and wait for the generated website URL.
